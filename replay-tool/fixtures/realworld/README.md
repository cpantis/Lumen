# Recordings written by the official MCAP writers

Generated by `scripts/gen-realworld.py` with the official Python packages `mcap`,
`mcap-ros2-support`, `mcap-ros1-support`, `mcap-protobuf-support` and
`foxglove-schemas-protobuf` — i.e. an implementation independent of the app — plus
deliberately damaged files. See the header of the script for the list. Regenerate with
`npm run gen:realworld` (requires the pip packages listed there).
